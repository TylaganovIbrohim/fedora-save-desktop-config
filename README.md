## 📖 О проекте
Это мои личные настройки Fedora Linux.  
Я собрал базовый и основной конфиг, который использую каждый день.  
⚡ Важно: это **под меня**, но если кому удобно — можете попробовать.  

## ⚙️ Как применить мои настройки
1. Установите программу **Save Desktop**.  
2. Скачайте файл [fedora-config.sd.zip](./fedora-config.sd.zip).  
3. В Save Desktop выберите «Импортировать конфиг» и примените мои настройки.  
4. После этого у вас будут те же темы, раскладки и оформление, что и у меня.
